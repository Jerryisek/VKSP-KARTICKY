Nejdůležitější vztahy ze skript Elektrické stroje v energetice

1. Základy, Vinutí a Indukované napětí

  • • Účinnost: η = P₂ / P₁ = P / P₁
  • • Mechanický výkon: P = M · ω = M · (2π·n / 60)
  • • Počet drážek na pól a fázi: q = Q / (2p · m)
  • • Krok cívky v drážkách: y = Q / 2p
  • • Synchronní otáčky: n_s = 60 · f / p [min⁻¹]
  • • Efektivní ind. napětí: U_i = 4,44 · f · N · Φ_max · k_v
  • • Pohybové napětí: u = B · l · v

2. Transformátory

  • • Zapínací proud: I_zap = (4 až 6) · I_n
  • • Poměrné napětí nakrátko: u_1k = (U_1k / U_1n) · 100 [%]
  • • Ustálený zkratový proud: I_1k = I_1n · (100 / u_1k)
  • • Roční náklady: N_r = N_0 + N_k + N_ú + O
  • • Průrazná pevnost oleje: min. 92 kV/cm (25 kV/3mm)

3. Asynchronní stroje

  • • Skluz: s = (n_s - n) / n_s
  • • Rotorová frekvence a napětí: f₂ = s · f₁ , U₂ = s · U₂₀
  • • Klossův vztah: M / M_zvr = 2 / (s/s_zvr + s_zvr/s)
  • • Závislost momentu na napětí: M ~ U₁²
  • • Řízení otáček: n = (60 · f₁ / p) · (1 - s)
  • • Řád drážkových harm.: ν = c · (Q / p) ± 1 = 2·m·q·c ± 1
  • • Ztráty v režimu brzdy: až 3× větší než při rozběhu

4. Synchronní a Stejnosměrné stroje

  • • Synchronní reaktance: X_d = X_r + X_1σ
  • • Moment synchr. hl. stroje: M ~ (U_f · U_b / X_d) · sin(β)
  • • Mez statické stability: β = π/2 (u vyniklých pólů < π/2)
  • • Napětí SS stroje: U_i = (p/a) · N_v · Φ₀ · n = k · Φ · n
  • • Moment SS stroje: M = c · Φ · I
  • • Napěťová rce: Dynamo U = U_i - R·I_a | Motor U = U_i + R·I_a
  • • Otáčky SS motoru: n ~ U / Φ (u sériového M ~ I² ~ 1/n²)
